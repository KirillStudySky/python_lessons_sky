# Автоматизированные UI-тесты (Selenium + Pytest + Allure)

Урок содержит автотесты для веб-приложений на базе паттерна **Page Object Model (POM)** с генерацией отчётов в **Allure**:

1. **Медленный калькулятор** (`Slow Calculator`) — проверка сложения чисел с заданной задержкой вычисления.
2. **Интернет-магазин Swag Labs** (`SauceDemo`) — сквозной сценарий авторизации, добавления товаров в корзину, проверки её содержимого и оформления заказа.

## Запуск тестов и просмотр отчёта Allure

### Способ 1. Автоматический запуск через скрипт `run_tests.sh` 

Скрипт очищает старые результаты, запускает тесты из `lesson_10/`, переносит историю предыдущих запусков для построения графиков трендов, генерирует HTML-отчёт в папку `final-report` и автоматически открывает его в браузере:

* **Linux / macOS:**
  ```bash
  chmod +x run_tests.sh
  ./run_tests.sh
  ```

* **Windows (через Git Bash):**
  ```bash
  bash run_tests.sh
  ```

### Способ 2. Ручной запуск по шагам

1. Запустите тесты с сохранением результатов в папку `results`:
   ```bash
   pytest lesson_10/ --alluredir=results
   ```

2. Сгенерируйте HTML-отчёт в папку `final-report`:
   ```bash
   allure generate results -o final-report --clean
   ```

3. Откройте сформированный отчёт в браузере:
   ```bash
   allure open final-report
   ```
